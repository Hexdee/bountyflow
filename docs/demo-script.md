# BountyFlow demo script · 90 seconds

**0:00–0:15 — Product**

“BountyFlow lets a project owner fund focused Web3 work in XLM escrow. Builders only get paid after proof is submitted and approved.” Show the responsive marketplace and the connected wallet profile.

**0:15–0:35 — Fund**

Open Post a bounty, enter a title, brief, reward, and deadline. Submit with Freighter. Point out the wallet approval, confirmation state, new marketplace card, and `created` event.

**0:35–0:55 — Deliver**

Open the bounty from a builder wallet, apply, then paste a GitHub PR or demo URL as proof. Show the lifecycle moving Open → Assigned → Submitted.

**0:55–1:15 — Approve**

Switch to the owner wallet and approve. Show the XLM payout transaction, `paid` event, and the updated completion/earned reputation stats.

**1:15–1:30 — Architecture**

Briefly show the README diagram: Bounty Escrow transfers native XLM and calls Reputation. Mention contract tests, frontend tests, CI, deployment script, and mobile layout.
